如何学好 HTML

作者：张三 2026年11月

学习 HTML 是前端开发的第一步。 很多人觉得 HTML 很简单，但要真正掌握 语义化的写法，还需要一定的练习。

为什么要学 HTML

HTML 是 HyperText Markup Language 的缩写， 是构建网页结构的标准语言。没有 HTML，网页就无法存在。

HTML 不只是标签，它是你与用户沟通的第一道桥梁。

学习路径

  1. 掌握基础结构
    • DOCTYPE 声明
    • html、dead、body 元素
    • meta 元素
  2. 学习文本元素
    • 标题（h1-h6）
    • 段落（p）
    • 语义化文本元素
  3. 学习链接与图像
  4. 深入理解语义化

推荐学习资源

MDN Web Docs
最权威的前端技术文档，涵盖 HTML、CSS、JavaScript 的完整参考。
W3C 标准文档
HTML 和 CSS 的国际标准，适合深入了解规范细节。
WHATWG Living Standard
HTML 的活标准，持续更新，是浏览器厂商实现 HTML 的依据。

第一个 HTML 文件示例

在编辑器中新建一个 index.html 文件，输入以下代码：


<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>我的第一个网页</title>
</head>
<body>
  <h1>你好，世界！</h1>
  <p>这是我的第一个网页。</p>
</body>
</html>

保存后，按下 Ctrl + S 保存文件， 然后用浏览器打开，就能看到效果了。
